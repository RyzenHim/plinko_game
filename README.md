# Plinko Lab (Provably Fair)

A production-quality implementation of a provably-fair Plinko game. Built as a full-stack engineering assignment.

## 🚀 Project Overview
Plinko Lab is an interactive game where balls drop through a triangular grid of pegs into buckets with varying multipliers. The game leverages a **Commit-Reveal protocol** and a **Deterministic Engine** to guarantee that every outcome is fair, pre-determined, and verifiable by the player.

## 🏗️ Architecture

### Backend (Node.js/Express)
- **Service-Oriented Architecture**: Business logic is isolated from controllers.
- **RESTful API**: Stateless endpoints for round management and verification.
- **Prisma ORM**: Type-safe database interactions with PostgreSQL.
- **Security**: Strict input validation and server-side secret management.

### Frontend (Next.js 15)
- **App Router**: Modern React architecture.
- **Tailwind CSS**: Utility-first responsive design.
- **Framer Motion**: High-performance, deterministic animations.
- **Web Audio API**: Low-latency, asset-free sound generation.

## 📊 Database Schema (Prisma)
The `Round` model tracks the complete lifecycle:
- `id`: Unique round identifier.
- `status`: `CREATED` | `STARTED` | `REVEALED`.
- `commitHex`: SHA256 of `serverSeed` + `nonce`.
- `serverSeed`: Secret generated by the server (revealed post-round).
- `clientSeed`: Provided by the user to influence entropy.
- `pathJson`: Full deterministic path storage for replay integrity.

## 🛡️ Fairness Specification

### Commit‑Reveal Protocol
1. **Commit**: Server generates a `serverSeed` and a `nonce`. It provides the user with a `commitHex = SHA256(serverSeed : nonce)`.
2. **Execute**: User provides a `clientSeed`. The system generates a `combinedSeed = SHA256(serverSeed : clientSeed : nonce)`.
3. **Reveal**: After the drop, the `serverSeed` is revealed. The user can hash it with the `nonce` to verify it matches the initial `commitHex`.

### Deterministic Engine
The engine uses the **xorshift32** PRNG seeded by the `combinedSeed`:
- **Peg Map**: Each peg is assigned a `leftBias` in `[0.4, 0.6]`, rounded to 6 decimals.
- **Drop Influence**: The selected column adjusts the bias by `±0.01` per column distance from center.
- **Outcome**: The ball's path is determined step-by-step using the PRNG. If `rand() < adjustedBias`, it goes Left; otherwise, Right.

## 🔌 API Documentation

### `POST /api/rounds/commit`
Initializes a round. Returns `roundId`, `commitHex`, and `nonce`.

### `POST /api/rounds/:id/start`
Starts the drop. Expects `clientSeed`, `betCents`, and `dropColumn`. Returns outcome summary.

### `POST /api/rounds/:id/reveal`
Reveals the secret `serverSeed`.

### `GET /api/verify`
Public endpoint for external verification. Recomputes outcome from seeds.

## 🛠️ Local Setup

### 1. Prerequisites
- Node.js v18+
- PostgreSQL database (Supabase recommended)

### 2. Installation
```bash
# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install
```

### 3. Environment Variables
Create a `.env` in the `backend/` folder:
```env
DATABASE_URL="your_postgresql_url"
PORT=5000
```

### 4. Database Migration
```bash
cd backend
npx prisma db push
```

### 5. Running the Apps
```bash
# Start Backend (from backend/)
npm run dev

# Start Frontend (from frontend/)
npm run dev
```
